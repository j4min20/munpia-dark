# 문피아 다크

문피아 다크 모드 확장 프로그램. PC Chrome용 비공식 확장입니다.

## 설치

1. [최신 버전 다운로드](https://github.com/j4min20/munpia-dark/releases/latest)에서 `munpia-dark-v1.zip`을 내려받습니다.
2. ZIP을 보관할 폴더에 압축 해제합니다. 설치 후에도 이 폴더를 삭제하거나 옮기지 마세요.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
6. 이미 열려 있던 문피아 페이지를 새로고침합니다.

## 기능

- 홈·작품 목록·상세·내서재·뷰어 주변 UI 다크 스타일
- 다크 모드 ON/OFF 스위치
- 본문을 밀지 않고 즉시 열리는 리모컨
- 선호작에서 작품 상세로 진입할 때 리모컨 한 번 닫기
- 뷰어 높이 맞춤 및 스크롤바 숨김

뷰어 본문 글자색·배경색 설정은 변경하지 않습니다. 높이 맞춤과 스크롤바 숨김은 다크 모드 OFF 상태에서도 유지됩니다. 모든 기능을 끄려면 Chrome 확장 프로그램 관리에서 확장을 비활성화하세요.

## 참고

문피아 페이지의 화면 요소를 로컬에서 검사하고, ON/OFF 설정만 Chrome 동기화 저장소에 보관합니다.

문피아가 제작하거나 보증하는 공식 제품이 아닙니다. 사이트 개편에 따라 일부 표시가 달라질 수 있습니다. 다른 다크 모드 확장과 동시 사용하면 충돌할 수 있습니다.

문제는 이 저장소의 Issues에 남겨주세요.

ZIP으로 설치한 확장은 자동 업데이트되지 않습니다. 새 버전을 받으면 기존 폴더의 파일을 교체하고 확장 프로그램 관리에서 새로고침하세요.
